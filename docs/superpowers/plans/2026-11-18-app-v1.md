# App V1 (Android) — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax.

**Goal:** App Android funcional de V1: jardín con cuadrícula, hábitos-árbol, check-in diario, strikes, cheat days, cuidado diario, tratamientos con gestos, logros y persistencia SQLite local.

**Architecture:** `JardinDeHabitos.Core` concentra toda la lógica (dominio + `GardenService` + persistencia SQLite vía `sqlite-net-pcl`) con TDD. `JardinDeHabitos.App` (MAUI, solo `net10.0-android`) es UI delgada: páginas + dibujo vectorial con `Microsoft.Maui.Graphics`.

**Tech Stack:** .NET 10, MAUI Android (API 36), sqlite-net-pcl, xUnit.

**Spec:** `CLAUDE.md`.

## Global Constraints

- Máximo 10 hábitos.
- `AbstinenciaTotal` nunca tiene cheat days; `Moderable` 1-2 días fijos por semana.
- Strikes: 1 roto = 2 días cuidado; 2 seguidos = +5 (total 7); 3 seguidos = muerte y reset a 0.
- Cicatrices solo se borran al morir u opcionalmente desde 180 días.
- Etapas: 0/1/3/5/7/30/180/365 días fijos.
- Logros a nivel usuario, persisten aunque el árbol muera. LeyendaCaida es SECRETO: no se lista antes de desbloquearse.
- Tratamientos = mini-juegos con gestos (tocar/arrastrar), nunca solo botones.
- Sin detección automática de apps, sin funciones sociales, un dispositivo.
- Estilo: vectorial plano, degradados cálidos (verdes, cafés, amarillos), lo-fi. Nada de pixel art.
- Tiempo siempre por `TimeProvider` (modo acelerado disponible en Debug).

## Rulings (huecos de la spec, decididos de forma conservadora)

- R1 Cheat days: `Habit.DiasDeCheat` (0-2 `DayOfWeek`, solo Moderable). Plantilla se reutiliza sola cada semana; se edita al crear el hábito o los sábados. En día de cheat no se pide check-in; los días de cheat no cuentan como hueco entre rotos.
- R2 Día sin check-in (no cheat): neutral, pero corta "seguidos" (ya implementado).
- R3 Regar/podar: libres, sin efecto en reglas; se guarda la última vez para mostrar "regado hoy / podado hoy".
- R4 Tratamiento: mientras hay penalización activa el árbol muestra plaga (Strike1) o plaga + raíces podridas (Strike2). Un tratamiento al día la limpia visualmente ese día. Sin efecto en reglas (la spec no define consecuencia).
- R5 Logro FrutaLegendaria: se registra la primera vez que cualquier árbol llega a esa etapa (se evalúa al refrescar el jardín).
- R6 Notificación de cheat day: alarma diaria 9:00 que avisa solo si hoy es cheat day de algún hábito.

### Task 1: Calendario de cheat days (Core)
- Modify `Habit.cs`: `public List<DayOfWeek> DiasDeCheat { get; set; } = []`.
- Create `CheatDaySchedule.cs`: `static bool EsDiaDeCheat(Habit, DateOnly)`, `static void Validar(Habit)` (Moderable: 0-2 días distintos; AbstinenciaTotal: 0), `static bool PuedeEditar(DateOnly hoy)` (sábado).
- Modify `CheckInProcessor`: CheatDay solo si `EsDiaDeCheat(hoy)`; Cumplido/Roto en día de cheat lanza; hueco entre check-ins ignora días de cheat.
- Tests: Roto sáb, (dom cheat sin check-in), Roto lun → Strike2; CheatDay en día no-cheat lanza; validar 3 días lanza; AbstinenciaTotal con días lanza.

### Task 2: Logros (Core)
- Create `Logro.cs` enum `{ FrutaLegendaria, LeyendaCaida }`, `LogroInfo` (nombre, descripción, `EsSecreto`).
- Tests en Task 3 (los dispara `GardenService`).

### Task 3: GardenService + almacén (Core)
- Create `IGardenStore` (CRUD de `HabitRecord` = Habit + StrikeState + fechas de cuidado; logros; historial de check-in).
- Create `InMemoryGardenStore` (tests) y `SqliteGardenStore` (`sqlite-net-pcl`).
- Create `GardenService(IGardenStore, GrowthStageCalculator)`:
  `CrearHabito`, `Habitos()` (con etapa, días, penalización activa, si pide check-in hoy, si puede borrar cicatrices), `CheckIn`, `Regar`, `Podar`, `RegistrarTratamiento`, `BorrarCicatrices`, `EditarDiasDeCheat`, `EliminarHabito`, `LogrosVisibles()`.
- Tests: límite 10 hábitos; check-in persiste; muerte dispara LeyendaCaida solo si era legendaria; FrutaLegendaria se registra una vez; LeyendaCaida no aparece en `LogrosVisibles` antes; SQLite ida y vuelta con archivo temporal.

### Task 4: App MAUI
- Create `src/JardinDeHabitos.App` (`net10.0-android`, `ApplicationId org.jardindehabitos.app`).
- Páginas: `JardinPage` (cuadrícula 2 columnas, máx 10), `NuevoHabitoPage`, `ArbolPage` (árbol grande, check-in, regar/podar con gestos, tratamiento), `LogrosPage`.
- `TreeDrawable` (Maui.Graphics): 8 etapas, degradados cálidos, overlays de plaga/raíces/“en paz”.
- Mini-juegos: plaga = tocar bichos; raíces = arrastrar raíces fuera; regar = arrastrar regadera sobre el árbol; podar = deslizar sobre ramas.
- Notificación diaria de cheat day (AlarmManager + BroadcastReceiver).
- Verificar: `dotnet build -f net10.0-android`, instalar en emulador, capturas.
